Guía de Integración para Desarrolladores: ¿Cómo codear tu plantilla para sincronizarla?

Añade estas etiquetas dinámicas o identificadores (IDs) en tu HTML para que el dueño de la tienda pueda editar textos, colores e imágenes desde el panel visual sin tocar código.

▾
🏷️ Variables Dinámicas (Tags Blogger)
{{store_name}} Nombre comercial de la tienda
{{store_tagline}} Eslogan / Subtítulo
{{store_logo}} Emoji o icono del logo
{{primary_color}} Color corporativo hex (ej: #2563eb)
{{announcement_text}} Mensaje de la barra superior
{{hero_tag}} Insignia flotante superior
{{hero_title}} Título principal del Hero
{{hero_desc}} Descripción o párrafo del Hero
{{hero_cta}} Texto del botón principal
{{contact_phone}} Teléfono WhatsApp
{{contact_email}} Correo oficial
{{contact_address}} Dirección física
🎯 Identificadores HTML (IDs Recomendados)
id="storeBrandName" Contenedor del nombre de la marca
id="storeBrandIcon" Contenedor del icono/logo
id="heroTitle" Título principal del Hero
id="heroTagText" Texto de la insignia
id="heroDesc" Párrafo descriptivo del Hero
id="heroPrimaryCta" Botón de llamada a la acción
id="topBarText" Barra superior de avisos
var(--primary) Variable CSS del color de marca
var(--radius-md) Variable CSS del radio de botones
Insertar Tag Rápido en Código:
📄 template.html HTML5 + CSS + Dynamic Tags
